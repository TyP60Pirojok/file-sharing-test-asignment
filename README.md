Сервис обмена файлами</br>

Системные требования:</br>
Windows 7/8/10/11</br>
Java 11 или выше</br>
</br>
Инструкция по запуску:</br>
Скачайте репозиторий архивом.</br>
Распакуйте папку в любое удобное место</br>
Запустите server.bat</br>

Сервер запустится и автоматически откроет в браузере страницу сервиса обмена файлами "Грузи-качай"</br>
Вы можете либо нажать на специальное окошко, либо перенести туда файл.</br>
Файл загрузится на наш локальный сервер и будет доступен для скачивание по ссылке ниже окна выбора файла.</br>
Также реализована статистика по файлам, которые мы загружали на сервер. (Но для скачивания всегда будет доступен только последний добавленный.)
